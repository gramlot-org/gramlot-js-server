gramlot-serverless
==================

.. image:: _static/gramlot-logo.png
   :alt: Gramlot logo
   :width: 160

Standalone exporter for Gramlot JavaScript pages: one HTML file, or one static
directory, that opens from disk without a server. The Page runs in a Web Worker.
`The Gramlot family <https://gramlot.readthedocs.io/en/latest/docs/public/055-family.html>`_
describes the core and the other repositories.
