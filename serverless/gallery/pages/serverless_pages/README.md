# No server

Pages exported by `@gramlot/gramlot-serverless`: one HTML file, or one folder for a
site. The page runs in a Web Worker of the browser; the window renders it and runs
the methods of its `Logic`. The file opens from disk, travels by mail or sits on any
static web site. There is no Python, the Source requests answer from the Worker, and
the data stay in the browser of whoever uses the page.
