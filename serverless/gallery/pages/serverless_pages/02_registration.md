# Registration form

The page written by `npm create @gramlot page my-form`. The summary is a method of
`Logic`; the buttons call `gramlot.utl.inout`:

- **Send by email** prepares an email with the data in the mail program of the user;
- **Save** writes a file that **Reload a saved file** reads back with the exact types;
- **Download JSON** exports the data for other programs.

```sh
npm run build    # gramlot-serverless build index.js -o index.html
```
