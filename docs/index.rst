gramlot-js-server
=================

.. image:: _static/gramlot-logo.png
   :alt: Gramlot logo
   :width: 160

Node.js and Bun host adapter for JavaScript Gramlot pages. Gramlot describes
web interfaces in Python or JavaScript and keeps them bound to application
state in the browser; see `The Gramlot family
<https://gramlot.readthedocs.io/en/latest/docs/public/055-family.html>`_ for
the core and the other repositories.
