# @gramlot/gramlot-browser

Standalone exporter for JavaScript [Gramlot](https://github.com/gramlot-org/gramlot)
pages: one HTML file, or one static directory, that opens without a server. The
Page runs in a Web Worker inside the browser.

```sh
npm install @gramlot/gramlot @gramlot/gramlot-browser
npx gramlot-browser build pages/index.js -o build/index.html
```

Quick start, guides and compatibility: the
[repository README](https://github.com/gramlot-org/gramlot-js-server#readme) and the
[documentation](https://gramlot-js-server.readthedocs.io/en/latest/105-introduction.html).
